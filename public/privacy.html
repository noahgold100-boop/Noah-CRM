Privacy Policy

Noah Gold Contacts (noah-crm-omega.vercel.app). Last updated November 3, 2026.

Noah Gold Contacts is a private contact manager used by one person, Noah Gold. It is not offered to the public, and only the account owner can sign in.

What the app accesses

  • Gmail (read-only): the app reads business email threads to keep contact records current. It never sends, replies to, labels, archives or deletes email.
  • Google Calendar: the app creates, moves and removes follow-up reminder events that it created itself. It does not read, change or delete any other events.
  • Basic profile: the owner's name and email address, used only to confirm who is signing in.

What is stored

For each business contact: name, email address, role, company, the date of the last conversation, a one-sentence summary of that conversation, a one-sentence note, and the date of the next follow-up. Full email contents are not stored. The Google access token is stored encrypted.

How data is processed

Email text is sent to Anthropic's Claude API to classify threads and write the short summaries. Data is hosted on Vercel and Neon (Postgres). These providers process data only to run the app. Nothing is sold, shared for advertising, or used to train models by this app.

Google API Services User Data Policy

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access and data

Access can be revoked at any time at myaccount.google.com/permissions. Contacts can be deleted inside the app, and all stored data can be deleted by removing the app's database.
